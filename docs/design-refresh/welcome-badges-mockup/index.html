The five-second trust test — what carries it
  • One job per screen: value copy states the promise, the three badges prove it, the CTA converts — nothing else on screen competes
  • Badge order = objection order: who made this (sage) → can I trust the advice (rose) → what does it cost (lavender) — a first-run mom's three questions, answered in sequence
  • Icons, not logo marks: hand-drawn stroke icons (organic sprig, leafy heart, hand-sketched heart with check) in the same imperfect stroke language as the week-spine sprigs — never geometric, never a brand mark
  • Cards float below the photo: dark moody hero washes to cream → cream badge cards with hand-cut rounded corners and soft grounded shadows stay high-contrast even over busy photo edges
  • Variant B fallback: plain cream with the icon resting in a lavender ring, same copy + badges — ship this one if the photo treatment fights the cards
  • Law compliance: cream #FAF8F5 · lavender #8E8CB5/#6E6C99 · rose #B87AA0 · sage #7C8F6F · charcoal #2A2A2A · Cormorant Garamond + Quicksand · paper-grain feTurbulence overlay · no blue, no violet accent, no emoji
