## Jeff's three called-out suspects — verdicts

1. **"The little plants used to show growth" → MISSING in the app, present in the deck.** The deck's render shows hand-drawn sprigs beside the WEEKLY TIP and WEEKLY AFFIRMATION kickers (mockup motifs SPROUT #7C8F6F and BUDDING #B085A5, `.sprig { margin-left:auto }`). `GrowthSprig.tsx` — a complete 4-stage sprout/leafing/budding/blossom vocabulary + GrowthDivider — was built and shipped as a component but has **zero mounts anywhere in `app/`**; the sole wave-2 reference is a code comment listing it as "a project dependency." No screen shows a growth plant today.
2. **Distinctive spacing → largely preserved, two flagged deltas.** Mockup-exact values are carried in code with self-documenting comments: seg `padding:4/marginTop:14` (home) & `margin:20/13` (kick), due-chip lavender pill, halo-behind-pad, strip/dots/recent constructs. Deltas: (a) Home `scrollContent.padding: 16` vs mockup `.content{padding:0 18px}`; (b) due-chip `marginTop:8/paddingH:10` vs `9/5-13`; (c) week chips restyled from 31px fixed circles (1.4px border) to transparent 2px-border pills.
3. **"The little pieces" → three small affordances didn't survive**: `See all ›` (kick recent card), `.wk.edge` faded outer stepper chips (+ deck's ellipsis run-out), the wavy hand-drawn "Week 20" underline. Also absent-in-practice: baby-card length/weight figures (data layer never supplies them — the facts row nil-renders).
